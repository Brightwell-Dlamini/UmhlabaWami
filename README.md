# Umhlaba Wami

**Manage Better. Respond Faster. Know More.**

## Status — Phases 1–5 complete

| Phase | Focus | Status |
|-------|--------|--------|
| 1 Foundation | Multi-role SPA | ✅ |
| 2 Real backend | Supabase dual-mode + Vercel | ✅ |
| 3 Operations | Centre Pulse, SLA, PM, vendors | ✅ |
| 4 Commercial | Pipeline, rent roll, deposits, board packs | ✅ |
| **5 Intelligence** | **Analytics, AI triage, permissions, compliance** | ✅ |
| 6 Ecosystem | APIs, white-label, PWA | Planned |

### Phase 5 highlights

- **Portfolio Intelligence** — health score, KPI strip, anomaly alerts  
- **AI Assist** — triage suggestions + natural-language search  
- **Permissions** — role matrix + per-user overrides  
- **Compliance Audit** — filterable trail, CSV export, POPIA note  
- **Notification Centre** — unread / mark all read

## Getting started

```bash
git clone https://github.com/Brightwell-Dlamini/UmhlabaWami.git
cd UmhlabaWami && npm install && npm run dev
```

Optional Supabase: see [docs/PHASE2_SETUP.md](docs/PHASE2_SETUP.md).
