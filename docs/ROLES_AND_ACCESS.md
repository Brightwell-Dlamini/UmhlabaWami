# Roles & who creates whom

## Hierarchy

```
Super Admin (platform)
  └── approves organisations
        └── Organisation Admin (landlord / client company)
              ├── Property Manager (runs the centre day-to-day)
              ├── Maintenance (technicians)
              ├── Finance
              └── Tenant users (shop operators)
```

## Super Admin

- Works for **Umhlaba Wami** (the platform), not for a shopping centre.
- **Does not** create property staff day-to-day.
- **Does:** approve or reject organisation applications, set org codes, oversee the platform, review listing leads.

## Organisation Admin ("Client Admin")

- Works for the **landlord / property company** (e.g. Ezulwini Commercial Holdings).
- Created after the org is approved (or by Super Admin once, then self-sufficient).
- **Creates:** property managers, maintenance, finance, and tenant login accounts for their organisation.
- Owns settings, branding, and who has access inside that company.

## Property Manager

- Works for the **organisation** (reports to Org Admin).
- Day-to-day centre operations: tickets, SLAs, tenants, leasing pipeline, roster.
- Does **not** typically create org-wide admins; focuses on operations.

## Maintenance

- Field technicians employed by (or contracted to) the organisation.
- Job queue, resolve tickets, preventive tasks.

## Finance

- Rent roll, deposits, board packs, payment recording for the organisation.

## Tenant

- A **shop / unit operator** leasing space from the organisation.
- Creates maintenance tickets, confirms fixes, views their lease documents.

## Short answers

| Question | Answer |
|----------|--------|
| Does Super Admin create users? | Only platform-level needs; **org staff are created by Organisation Admin**. |
| Who creates managers / techs / tenants? | **Organisation Admin** (Team screen). |
| Property Manager vs Org Admin? | Org Admin = company owner of the account. Property Manager = operational role for the centre. |
